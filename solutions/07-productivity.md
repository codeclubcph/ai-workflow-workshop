# Exercise 07 - Productivity wrap-up: solution

There is no single correct first-week plan. A useful plan should be actionable:

- **Task:** name a small, low-risk task that happens repeatedly.
- **Context:** list only the relevant files and repository rules.
- **Mode:** choose Ask for explanation, Plan for approach, or Agent for a
  reviewed implementation.
- **Verification:** name a concrete test, diff, or authoritative source that can
  reveal a plausible but incorrect result.
- **Boundary:** say what the assistant must not read, edit, execute, or send.

Example: "For weekly release notes, ask for a draft from merged PR titles and
the changelog only; compare every entry to the merged PRs; do not publish or
include customer data." Participants should adapt the example to their own
work and follow their organization's AI policy.
